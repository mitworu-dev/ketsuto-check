血糖コントロールチェック v1.1

■ 入っている機能
・毎日のチェックリスト
・タップごとのIndexedDB自動保存
・日付を切り替えて過去記録を閲覧
・1〜5のスケーリング
・血糖値が乱れているサインの記録
・自由メモ
・達成率の自動計算
・LINE報告用の全文コピー
・LINE報告用の短縮版コピー
・iPhone共有シート
・CSV書き出し
・JSONバックアップ／復元
・PWA対応（ホーム画面追加）
・オフライン対応（Service Worker）
・Persistent Storageの要求

■ iPhoneでアプリのように使う方法
このフォルダをHTTPSで配信する必要があります。
GitHub Pages / Cloudflare Pages / Netlifyなどの静的ホスティングに、このフォルダ内のファイルをそのまま置いてください。
公開URLをSafariで開き、共有メニュー →「ホーム画面に追加」で登録します。

※ index.htmlをiPhoneで単なるローカルファイルとして開くだけでは、PWA・Service Workerなどの機能が十分に動かないことがあります。

■ 記録について
記録はiPhone内のIndexedDBに保存され、ページが再読み込みされても復元されます。
ただし、ブラウザデータを手動削除した場合などに備えて、定期的に「バックアップ保存」でJSONファイルを保存してください。
CSVはExcel等で確認・分析するための出力です。

■ 元データ
ユーザー提供PDF「腸活チェックリスト - 血糖値コントロールリスト.pdf」を元に作成。
原文の項目構成を尊重し、チェックしやすい文に一部整形しています。
「一口に月30回以上よく噛んで食べる」「果糖ぶどう液糖」など、原文表記は基本的に維持しています。
